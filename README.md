# 8051 IR Transmitter and Receiver

> **Status:** Circuit and firmware reconstruction in progress.

A practical embedded-systems project based on an 8051 microcontroller and infrared communication. The original work involved hardware installation and testing of a transmitter/receiver setup, providing hands-on experience with microcontroller interfacing and system debugging.

## Engineering focus

- 8051 microcontroller programming
- Infrared transmitter/receiver communication
- Embedded hardware installation
- Peripheral interfacing
- End-to-end hardware testing

## Planned structure

```text
├── firmware/        # Recreated transmitter/receiver firmware
├── docs/            # Schematic, protocol notes, and pin map
├── assets/          # Verified hardware photographs and demo
└── tests/           # Range and communication test records
```
